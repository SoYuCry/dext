## 🎯 异常处理系统

### CRITICAL 异常（会停止策略）🔴

1. **HedgeFailed** - 对冲订单失败
   - 触发条件：Backpack 对冲订单失败
   - 影响：产生单边敞口
   - 行为：发送 TG 告警 + 停止策略

2. **InsufficientMarginForHedge** - 对冲端保证金不足
   - 触发条件：Backpack 保证金不足
   - 影响：无法对冲新仓位
   - 行为：发送 TG 告警 + 停止策略

3. **PositionImbalance** - 仓位严重不平衡
   - 触发条件：Aster 和 Backpack 仓位差异过大
   - 影响：表明对冲失败
   - 行为：发送 TG 告警 + 停止策略

### WARNING 异常（仅告警）⚠️

1. **QuoteOrderFailed** - 做市订单失败
   - 触发条件：Aster 做市订单失败率 ≥ 50%
   - 影响：做市深度减少
   - 行为：发送 TG 告警 + 继续运行

2. **InsufficientMarginForQuotes** - 做市端保证金不足
   - 触发条件：Aster 保证金不足
   - 影响：无法挂新单
   - 行为：暂停做市 + 继续监控

## ⚠️ 风险提示

### 已知风险

1. **缺少平仓逻辑** ⚠️
   - 仓位会持续累积
   - 需要手动平仓
   - 建议定期检查仓位

2. **价格差异风险** 🟡
   - XAU 和 PAXG 价格可能偏离
   - 长期可能导致仓位偏移
   - 建议监控价差

3. **资金费率风险** 🟡
   - Aster 和 Backpack 资金费率不同
   - 长期持仓会累积费用
   - 建议监控资金费率

### 紧急情况处理

**如果收到 CRITICAL 告警**:

1. **立即检查仓位**
   ```bash
   python scripts/check_positions.py
   ```

2. **如果有单边敞口，立即对冲**
   ```bash
   python scripts/emergency_hedge.py
   ```

3. **分析原因**
   - 保证金不足？→ 充值
   - API 问题？→ 检查 API 状态
   - 网络问题？→ 检查连接

4. **修复后重启**
