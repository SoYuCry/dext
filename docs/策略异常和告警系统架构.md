## 🎯 设计目标

创建一个**可被所有策略复用**的异常和告警系统，具有：

1. ✅ **统一的接口** - 所有策略使用相同的异常类型和告警方法
2. ✅ **分级处理** - CRITICAL/WARNING/INFO 三个严重级别
3. ✅ **可扩展性** - 易于添加新的异常类型和告警渠道
4. ✅ **自动化** - 异常自动触发告警，减少重复代码

## 🔧 核心组件

### 1. 异常基类系统 (`strategies/base_exceptions.py`)

#### 严重度枚举

```python
class Severity(str, Enum):
    CRITICAL = "CRITICAL"  # 必须停止策略
    WARNING = "WARNING"    # 告警但可继续
    INFO = "INFO"          # 仅记录
```

#### 基类

```python
class StrategyException(Exception):
    """所有策略异常的基类"""
    
    severity: Severity = Severity.INFO
    
    def __init__(self, message: str, details: dict = None, action: str = None):
        self.message = message
        self.details = details or {}
        self.action = action or self._default_action()
    
    def to_dict(self) -> dict:
        """序列化为字典，用于日志和告警"""
        return {
            "type": self.__class__.__name__,
            "severity": self.severity.value,
            "message": self.message,
            "details": self.details,
            "action": self.action,
        }
```

#### 内置异常类型

**CRITICAL 异常**（必须停止策略）:

| 异常类 | 触发条件 | 使用场景 |
|--------|---------|---------|
| `HedgeFailed` | 对冲订单失败 | 对冲策略、套利策略 |
| `InsufficientMarginCritical` | 关键操作保证金不足 | 对冲、平仓 |
| `PositionImbalance` | 仓位严重不平衡 | 对冲策略 |
| `ExchangeConnectionLost` | 交易所连接丢失 | 所有策略 |

**WARNING 异常**（告警但可继续）:

| 异常类 | 触发条件 | 使用场景 |
|--------|---------|---------|
| `OrderFailed` | 订单失败 | 做市、交易 |
| `InsufficientMarginWarning` | 非关键操作保证金不足 | 做市 |
| `HighFailureRate` | 操作失败率高 | 批量操作 |
| `PriceFeedStale` | 价格数据过期 | 所有策略 |

**INFO 异常**（仅记录）:

| 异常类 | 触发条件 | 使用场景 |
|--------|---------|---------|
| `OrderPartiallyFilled` | 订单部分成交 | 所有策略 |
| `StrategyPaused` | 策略暂停 | 所有策略 |
| `StrategyResumed` | 策略恢复 | 所有策略 |

### 2. 告警系统 (`strategies/base_alerts.py`)

#### 告警渠道接口

```python
class AlertChannel(ABC):
    """告警渠道抽象基类"""
    
    @abstractmethod
    def send(self, severity: str, title: str, message: str, details: dict) -> bool:
        """发送告警"""
        pass
    
    @abstractmethod
    def is_enabled(self) -> bool:
        """检查是否启用"""
        pass
```

#### 内置渠道

**1. TelegramChannel** - Telegram 通知
```python
channel = TelegramChannel(
    bot_token="your_bot_token",
    chat_id="your_chat_id"
)
```

**2. LogChannel** - 日志记录（总是启用）
```python
channel = LogChannel()
```

#### 告警管理器

```python
class AlertManager:
    """管理多个告警渠道"""
    
    def __init__(self, channels: List[AlertChannel] = None):
        # 默认：Log + Telegram
        pass
    
    def send_critical(self, title: str, message: str, details: dict = None):
        """发送 CRITICAL 告警"""
        pass
    
    def send_warning(self, title: str, message: str, details: dict = None):
        """发送 WARNING 告警"""
        pass
    
    def send_exception(self, exc: Exception):
        """自动发送异常告警（根据异常类型判断严重度）"""
        pass
```

## 💡 使用示例

### 1. 在策略中使用异常

```python
from strategies.base_exceptions import (
    HedgeFailed,
    InsufficientMarginCritical,
    HighFailureRate,
)
from strategies.base_alerts import send_exception_alert

# CRITICAL: 对冲失败
try:
    hedge_order = await exchange.create_order(...)
    if not hedge_order:
        raise HedgeFailed(
            primary_info={'side': 'BUY', 'qty': 0.002, 'price': 4596},
            hedge_exchange='backpack',
            error='Order failed'
        )
except HedgeFailed as e:
    send_exception_alert(e)  # 自动发送 CRITICAL 告警
    raise  # 重新抛出，停止策略

# WARNING: 高失败率
if failure_rate >= 0.5:
    exc = HighFailureRate(
        operation='quote_orders',
        failed=3,
        total=6,
        threshold=0.5
    )
    send_exception_alert(exc)  # 自动发送 WARNING 告警
    # 不抛出，继续运行
```

## 🎯 最佳实践

### 1. 异常选择原则

**使用 CRITICAL 的情况**:
- ✅ 对冲失败（产生单边敞口）
- ✅ 关键操作保证金不足
- ✅ 仓位严重不平衡
- ✅ 交易所连接丢失
- ✅ 任何可能导致资金损失的情况

**使用 WARNING 的情况**:
- ✅ 非关键订单失败
- ✅ 做市保证金不足
- ✅ 操作失败率高
- ✅ 价格数据延迟
- ✅ 性能降级

**使用 INFO 的情况**:
- ✅ 订单部分成交
- ✅ 策略状态变化
- ✅ 配置更新
- ✅ 一般性信息

### 2. 告警频率控制

```python
# 避免告警轰炸
from datetime import datetime, timedelta

class RateLimitedAlertManager(AlertManager):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._last_alert_time = {}
        self._min_interval = timedelta(minutes=5)
    
    def send_warning(self, title: str, message: str, details: dict = None):
        # 同类型告警 5 分钟内最多发送 1 次
        key = f"WARNING:{title}"
        now = datetime.now()
        
        if key in self._last_alert_time:
            if now - self._last_alert_time[key] < self._min_interval:
                logger.debug(f"Skipping duplicate alert: {title}")
                return
        
        self._last_alert_time[key] = now
        super().send_warning(title, message, details)
```

### 添加新的告警渠道

```python
# strategies/base_alerts.py

class WebhookChannel(AlertChannel):
    """Webhook 告警渠道"""
    
    def __init__(self, webhook_url: str):
        self.webhook_url = webhook_url
    
    def is_enabled(self) -> bool:
        return bool(self.webhook_url)
    
    def send(self, severity: str, title: str, message: str, details: dict) -> bool:
        try:
            payload = {
                'severity': severity,
                'title': title,
                'message': message,
                'details': details,
                'timestamp': datetime.now().isoformat(),
            }
            response = requests.post(self.webhook_url, json=payload, timeout=5)
            response.raise_for_status()
            return True
        except Exception as e:
            logger.error(f"Webhook alert failed: {e}")
            return False
```
